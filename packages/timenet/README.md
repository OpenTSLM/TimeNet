# timenet

The TimeNet SDK and CLI: the TimeF format plus dataset, writer, and reader definitions for
registering, querying, downloading, converting, and exploring time series datasets.

Part of the [TimeNet](https://github.com/OpenTSLM/TimeNet) workspace. Dataset-specific integrations live in the
separate [`timenet-connectors`](../timenet-connectors) package.

## Install

```bash
pip install timenet
```

## Usage

```bash
timenet
```
