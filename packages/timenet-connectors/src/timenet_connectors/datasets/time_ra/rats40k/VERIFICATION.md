# Verification: `time-ra/rats40k`

- **Checklist version:** 2

Status is one of ✅ Done, ☑️ Done once, ⚠️ Open or ⚪ N/A, or a combination such as
✅ Done / ⚠️ Open. Every row needs evidence, and a ✅ Done row names its test or build check in
backticks. "Choosing a status" in `docs/connector-verification.md` gives the rules. When in doubt,
pick the weaker status.

Tests named below are in `tests/test_connector.py` unless stated otherwise. The ☑️ Done once
checks are one-off passes run on 2026-10-25 over the two Hub files listed under References and two
full builds of dataset version 1.0.0, read back through `TimeNet.load`. The source was parsed for
them with `json.load` and a regular expression for the multivariate channels, not with the
connector's streaming parser. Their scripts aren't in the repo yet (see Plan).

On 2026-10-27, after the connector was moved onto the loader layout and TimeNet began numbering
ids itself, these were rerun on two new full builds: the read-back against the raw files (#13,
#16, #48), the determinism comparison (#17), the size (#57), and a dummy evaluation with the
authors' parser and metrics (#54).

## References

The connector reads two files from `Time-RA/RATs40K` at commit `dc968d6a`, which was also `main`
on 2026-10-25:

- `RATs-Uni-TSImage_Reason.json`, 93,161,661 bytes, sha256 `12fe8e2f…3321`, equal to the Hub's
  LFS id.
- `RATs-Multi-TSImage_Reason.json`, 8,117,524 bytes, sha256 `3b8af1a2…f37f`. It is a plain git
  file, so the Hub publishes no sha256 for it.

Independent copies and references, which the connector doesn't read:

- **The Hub dataset card** at `dc968d6a`: 39,574 samples, 10 domains, an 83.7% anomaly ratio,
  "14 Univariate + 6 Multivariate" categories, and `license: apache-2.0`. Its JSON example
  (`Index`, nested `Observation`, integer `Label`) doesn't match the files' fields (#5).
- **The authors' code**, yyysjz1997/Time-RA at commit `200b244f`: `prompts/` (both evaluation
  prompts and each variant's `ANOMALY_DICT`), `eval2file.py` (the metrics),
  `eval_anomaly_multiclf_reason*.py` (how a request is built and an answer parsed),
  `labeling/gen_reason_label_with_gpt*.py` (the labelling prompt, given `Label`) and
  `labeling/rank_models.py` (the GPT-4 ranking that fills `Rank` and starts every test key as
  `None`).
- **The paper**, TIME-RA, arXiv:2507.15066: Table 1 (39,574 samples, 83.7% anomalies),
  Section 3.3 (36,311 univariate and 3,274 multivariate instructions) and Appendix B (lengths
  16–128). The text gives no split sizes.
- `figures.zip` and `figures_multi.zip` on the Hub hold the rendered plots that `FigurePath`
  names. They weren't downloaded.

The upstream series (UCR, NASA, Yahoo, MITDB and the AIOps challenges, per the card) aren't
mapped to rows anywhere in the release, so no row can be compared with its original recording.
